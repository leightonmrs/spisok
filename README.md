# Хочу прочитать

Личный список книг. Откройте [index.html](index.html) в браузере с разрешённым локальным хранилищем. Страница работает без интернета и сохраняет список, статус прочтения и оценки в браузере.

## Что умеет страница

- Добавлять книги в раздел «Хочу прочитать» по названию и, при желании, автору.
- Перемещать книги в раздел «Прочитано» кнопкой «Отметить прочитанной».
- Ставить и менять оценку от 1 до 5 после прочтения. Оценку можно поставить позже.

## Как проверить

1. Добавьте «Маленький принц» с автором «Антуан де Сент-Экзюпери», затем «Хоббит» без автора. Обе книги должны появиться в разделе «Хочу прочитать».
2. Попробуйте добавить книгу с названием из одних пробелов. Список должен остаться прежним.
3. Обновите страницу. Обе книги должны остаться в списке.
4. Отметьте «Хоббит» прочитанным. Он должен появиться один раз в разделе «Прочитано» без оценки. «Маленький принц» должен остаться в разделе «Хочу прочитать».
5. Поставьте «Хоббиту» 4, затем измените оценку на 5. Обновите страницу. «Хоббит» должен остаться в разделе «Прочитано» с оценкой «5 из 5», а «Маленький принц» — в разделе «Хочу прочитать» с автором.
6. Отметьте «Маленький принц» прочитанным и поставьте ему 1. Проверьте, что автор сохранился и у «Хоббита» по-прежнему «5 из 5».
7. Повторите добавление, отметку о прочтении и изменение оценки при ширине окна 375 px. Все элементы управления должны быть доступны без горизонтальной прокрутки.
