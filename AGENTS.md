# AGENTS.md — <Спискок "хочу прочитать">

## О проекте
«Хочу прочитать» — личный список книг, которые я планирую прочитать. Он помогает быстро записать название и автора, чтобы вернуться к книге позже.
Файлы: index.html — разметка, styles.css — вид, script.js — логика.
Требования к функциям — в папке specs/. Описание для людей — в README.md.

## Правила
- Только HTML, CSS и JavaScript в этой папке. Без npm, библиотек и внешних ресурсов.
- Данные храни в браузере (localStorage). Ничего не отправляй в интернет.
- Интерфейс на русском языке, подписи короткие и понятные.
- Кнопки и поля не меньше 44px, страница работает на телефоне шириной 375px.
- Делай только то, о чём попросили. Работающие функции не ломай.

## Как проверить
- Введи название «Маленький принц» и автора «Антуан де Сент-Экзюпери». Нажми «Добавить». В списке появится книга с названием и автором.
- Введи только название «Хоббит» и нажми «Добавить». Книга появится в списке.
- Введи в поле названия только пробелы и нажми «Добавить». Новая запись не появится.
- Нажми F5. Обе добавленные книги останутся в списке.
