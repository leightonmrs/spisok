# Удаление и перенос книг

## Для кого и зачем

Владелец списка может удалить лишнюю запись или выбрать другой раздел, если начал перечитывать книгу, отложил её или случайно отметил прочитанной.

## Что должно быть

- Рядом с каждой книгой во всех трёх разделах есть кнопка «×» с доступным названием «Удалить книгу „Название“». Нажатие открывает подтверждение с названием книги. При отмене запись остаётся на месте.
- Из любого раздела книгу можно перенести в любой из двух других. Существующие кнопки «Начать читать» и «Отметить прочитанной» остаются доступными там, где они есть сейчас. Для обратных переходов используются подписи «В раздел „Читаю“» и «В раздел „Хочу прочитать“».
- При переносе сохраняются название, автор, тип и оценка. Если вернуть книгу в «Прочитано», она снова покажется с прежней оценкой.

## Примеры

- У «Йеллоуфейс» в разделе «Прочитано» стоит 3 из 5. Перенесите книгу в «Читаю», затем в «Хочу прочитать» и снова в «Прочитано». В списке должна быть одна запись с оценкой 3 из 5.
- Нажмите «×» у книги «0» и отмените удаление. Книга останется в списке. Нажмите «×» снова и подтвердите удаление. Исчезнет только выбранная запись.

## Ограничения

- Изменения сохраняются в браузере через localStorage. Действия доступны и для книг, добавленных до обновления.
- При включённых фильтрах список обновляется сразу после действия. Если книга перестала подходить под фильтр, она исчезает из результатов.
- Все кнопки имеют область нажатия не меньше 44 × 44 px. При ширине экрана 375 px действия доступны без горизонтальной прокрутки.

## Готово, когда

- Из каждого раздела книгу можно отправить в любой из двух других. После обновления страницы книга остаётся в выбранном разделе в одном экземпляре.
- После переноса «Йеллоуфейс» по шагам из примера сохраняются автор, тип и оценка 3 из 5.
- В каждом разделе кнопка «×» удаляет только выбранную запись после подтверждения, в том числе если несколько книг имеют одинаковое название. Отмена сохраняет запись. Удалённая книга не возвращается после обновления страницы.
- При активном фильтре по статусу перенос в другой раздел сразу убирает книгу из результатов. После сброса фильтра книга видна в новом разделе.
- На ширине 375 px можно перенести и удалить книгу без горизонтальной прокрутки. Добавление книг и изменение оценки работают по прежним шагам из README.
