# Резервная копия списка книг

## Для кого и зачем

Для владельца списка, который хочет сохранить книги перед очисткой данных браузера или перенести их в другой браузер.

## Что должно быть

- Кнопка «Скачать копию» сохраняет весь список в файл JSON, включая книги, скрытые фильтрами. В копии сохраняются названия, авторы, типы, статусы, оценки и порядок добавления.
- Кнопка «Выбрать копию» открывает файл и показывает общее число книг и число книг в каждом из трёх разделов. До подтверждения список остаётся прежним.
- Действие «Добавить из копии» дополняет текущий список. Совпадением считаются одинаковые название и автор после удаления пробелов по краям и без учёта регистра. При совпадениях с текущим списком или внутри файла пользователь выбирает, какие записи добавить. По умолчанию совпадения пропускаются.
- Действие «Заменить список» восстанавливает все записи и их порядок из копии. Перед заменой видно, сколько текущих записей будет удалено и сколько записей войдёт в восстановленный список. Отмена оставляет текущий список как есть.

## Примеры

- «Маленький принц» находится в «Хочу прочитать», а «Хоббит» — в «Прочитано» с оценкой 5. При выборе скачанной копии будут показаны две книги, по одной в соответствующих разделах.
- Если «Хоббит» уже есть в текущем списке, при добавлении из копии он отмечается как совпадение. Можно добавить только «Маленького принца» или явно выбрать ещё одну запись «Хоббита».
- Если после создания копии добавить «Йеллоуфейс», подтверждённая замена этой копией восстановит «Маленького принца» и «Хоббита». При отмене «Йеллоуфейс» останется в списке.

## Ограничения

- Файл обрабатывается в браузере без интернета. Данные сохраняются в localStorage.
- В файле указана версия формата. Неподдерживаемый, повреждённый или некорректный файл сопровождается сообщением об ошибке. Текущий список сохраняется целиком. При ошибке записи список тоже остаётся прежним.
- Можно скачать и открыть копию пустого списка. Замена на пустой список требует подтверждения с явным указанием, что записи будут удалены.
- На ширине 375 px все действия доступны без горизонтальной прокрутки. Кнопки и поля имеют размер не меньше 44 × 44 px.

## Готово, когда

- Скачанная копия содержит все книги и открывается в другом браузере с теми же данными и порядком.
- Предпросмотр показывает правильные числа, а повреждённый файл оставляет список прежним.
- При добавлении из копии сохраняются текущие записи и импортируются только выбранные совпадения и новые книги.
- Замена срабатывает только после подтверждения. Результат добавления и замены сохраняется после перезагрузки.

## Шаги

- [x] **Скачивание копии.** На странице появляется кнопка «Скачать копию». Проверка → добавить две книги, скрыть одну фильтром, скачать копию и открыть файл: в нём обе книги.
- [x] **Предпросмотр копии.** Появляются выбор файла, количество книг по разделам и сообщение об ошибке. Проверка → открыть правильную копию, сверить числа, затем выбрать повреждённый файл: исходный список сохраняется.
- [x] **Добавление из копии.** Появляются список совпадений с флажками и кнопка «Добавить из копии». Проверка → открыть копию с совпадением и новой книгой, оставить флажок совпадения снятым, нажать «Добавить из копии»: появляется только новая книга.
- [ ] **Замена списка.** Появляются кнопка «Заменить список» и подтверждение с количеством записей. Проверка → открыть копию, нажать «Заменить список» и отменить: текущие книги остаются. Повторить замену с подтверждением и обновить страницу: в списке книги из копии.
