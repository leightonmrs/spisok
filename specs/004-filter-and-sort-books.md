# Фильтры и сортировка книг

## Для кого и зачем

Для владельца списка, который хочет быстро найти книги нужного формата, увидеть книги на определённом этапе чтения или сравнить оценки прочитанного.

## Что должно быть

- В форме добавления книги есть необязательное поле «Тип» с вариантами «Печатная книга», «Электронная книга», «Аудиокнига». Если тип не выбран, у книги отображается «Тип не указан». Выбранный тип виден в записи книги.
- Над списком есть три фильтра. «Тип» предлагает все форматы и вариант «Не указан». «Оценка» предлагает все оценки, значения от 1 до 5 и вариант «Не оценено». «Статус» предлагает все статусы и каждый из трёх по отдельности — «Хочу прочитать», «Читаю», «Прочитано».
- При выборе нескольких фильтров видны только книги, которые подходят под каждое условие. «Не оценено» включает любую книгу без оценки, в том числе ещё не прочитанную. При выборе одного статуса виден только соответствующий раздел.
- В меню «Сортировка» есть варианты «По добавлению», «По типу», «Сначала высокие оценки», «Сначала низкие оценки» и «По статусу». По умолчанию разделы и книги идут в привычном порядке. Сортировка по типу упорядочивает книги по названию типа внутри раздела, оставляя книги без типа внизу. Сортировка по оценке действует внутри раздела и в обоих направлениях оставляет книги без оценки внизу. При одинаковых значениях сохраняется порядок добавления.
- Сортировка по статусу меняет порядок разделов на «Прочитано», «Читаю», «Хочу прочитать». Внутри каждого раздела книги идут по добавлению.
- Кнопка «Сбросить» возвращает все фильтры и сортировку к начальным значениям. Если ни одна книга не подходит, появляется сообщение «По выбранным фильтрам книг нет».
- Результаты обновляются сразу при выборе фильтра или сортировки, добавлении книги, изменении оценки и переходе между статусами.

## Примеры

- Добавить «Йеллоуфейс» без типа и отметить прочитанной. В её карточке выбрать «Аудиокнига» вместо «Тип не указан». После обновления страницы выбранный тип сохраняется, и фильтр «Аудиокнига» показывает книгу.
- Добавить «Хоббит» как аудиокнигу, отметить прочитанной и поставить 5. Добавить «Маленький принц» как печатную книгу, отметить прочитанной и поставить 4. Фильтры «Аудиокнига», «5» и «Прочитано» показывают только «Хоббита». Если заменить оценку фильтра на 4, появляется сообщение об отсутствии результатов.
- Сбросить выбор. В разделе «Прочитано» при сортировке от высокой оценки к низкой «Хоббит» стоит первым, при обратной сортировке — вторым. Если добавить прочитанную книгу без оценки, она стоит последней в обоих случаях.
- Добавить книгу без типа, перевести её в «Читаю» и выбрать «Не указан», «Не оценено» и «Читаю». Книга видна. После перевода в «Прочитано» она сразу исчезает из результатов. При сортировке по статусу после сброса первым стоит раздел «Прочитано».

## Ограничения

- Книги, сохранённые раньше, доступны с прежними статусами и оценками. Отсутствующий тип считается неуказанным. Тип сохраняется вместе с книгой в localStorage.
- Фильтры и сортировка меняют только отображение. После обновления страницы элементы управления возвращаются к начальным значениям.
- Оценку по-прежнему можно поставить только прочитанной книге. Используются целые оценки от 1 до 5.
- Русские подписи, чистые HTML, CSS и JavaScript, работа без интернета. Элементы управления не меньше 44 × 44 px и помещаются при ширине 375 px без горизонтальной прокрутки.

## Готово, когда

- Все примеры воспроизводятся, фильтры работают по отдельности и в сочетании, сброс возвращает полный список.
- Сортировка по типу ставит аудиокниги перед печатными и электронными книгами, а книги без типа — в конец каждого раздела. Сортировка по оценке и статусу даёт порядок, описанный выше.
- После обновления страницы книги сохраняют тип, статус и оценку. Записи без типа, сохранённые до обновления, доступны через фильтр «Не указан».
- У книги в отфильтрованном или отсортированном списке меняется её собственная оценка или статус.
- На ширине 375 px доступны все элементы управления и проходят проверки добавления, пустого названия и сохранения после обновления из AGENTS.md.
