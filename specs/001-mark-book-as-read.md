# Отметить книгу как прочитанную

## Для кого и зачем

Для читателя, который ведёт список «Хочу прочитать» и хочет видеть, какие книги ещё ждут своей очереди.

## Что должно быть

- Новая книга появляется в разделе «Хочу прочитать».
- У каждой книги в этом разделе есть кнопка «Отметить прочитанной».
- При нажатии книга исчезает из раздела «Хочу прочитать» и появляется в разделе «Прочитано». Название и автор сохраняются.
- После обновления страницы каждая книга остаётся в своём разделе.

## Примеры

- Добавить «Хоббит» без автора и «Маленький принц» с автором «Антуан де Сент-Экзюпери». Отметить «Хоббит» прочитанным. «Хоббит» появится в разделе «Прочитано», а «Маленький принц» останется в разделе «Хочу прочитать».
- Отметить «Маленький принц» прочитанным. Книга появится в разделе «Прочитано» вместе с автором.

## Ограничения

- Данные и статус чтения хранятся в localStorage. Страница не отправляет данные в интернет.
- Если у сохранённой книги ещё нет статуса чтения, она отображается в разделе «Хочу прочитать».
- Кнопки и поля размером не меньше 44 × 44 px. Оба раздела доступны при ширине экрана 375 px без горизонтальной прокрутки.

## Готово, когда

- Срабатывают оба примера. Каждая отмеченная книга отображается один раз.
- После обновления страницы сохраняются состав обоих разделов, названия и авторы.
- По-прежнему можно добавить книгу с автором или без него. Название из одних пробелов не добавляется.
- На экране шириной 375 px можно добавить книгу и отметить её прочитанной.
